Markdown Slides
---------------
Open index.html in Chrome/Edge/Firefox. No installation needed.

1. Create Slides -> write markdown on the left, preview on the right
2. Save with the Save button or Ctrl+S (saved in browser localStorage)
3. Edit Slides -> loads the saved slides back
4. Present Slides -> shows saved slides

Use --- on its own line to separate slides.
Keys: Left arrow, Right arrow, F11 (full screen), Ctrl+S (save)
Note: arrow keys will not change slide while the cursor is inside the text box.
